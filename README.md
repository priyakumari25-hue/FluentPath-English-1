# FluentPath English – Online-ready learning website

## Run locally
1. Extract this ZIP.
2. Open this folder in VS Code.
3. Open `index.html` using VS Code Live Server, or open it in a browser.

## Publish free with GitHub Pages
1. Create a new **public** GitHub repository, for example `fluentpath-english`.
2. Upload the contents of this folder (the `index.html`, `css`, and `js` folders) to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main`, folder `/ (root)`, and Save.
6. Wait for GitHub Pages to publish. The URL will be shown in Settings → Pages.

## Included content
- 6 CEFR levels (A1, A2, B1, B2, C1, C2)
- 12 lesson topics per level (72 lessons), each with Hindi explanation, English examples, a common mistake, correction and two practice questions
- 20 grammar chapters with Hindi explanations and English examples
- 12 original graded stories with comprehension questions
- Writing journal with simple offline suggestions
- Listening text-to-speech, speaking prompts and browser speech recognition where supported
- Level-wise checkpoint tests, vocabulary saver, XP and progress dashboard

## Important honest limitations
This is an online-ready static website, not a fully hosted commercial platform. It can be published on GitHub Pages and most learning features work in the browser. Login is a local learner profile, not secure cloud authentication. Progress and journal are stored in that browser only. Writing feedback is rule-based, not AI. Speaking recognition and text-to-speech depend on browser/device support. The course includes 72 structured lesson pages with starter explanations and exercises; it is not yet a complete professionally reviewed textbook for every CEFR learning outcome. The story collection is original short-form practice content, not a large collection of full novels. A real AI teacher, secure accounts, cross-device sync, extensive audio catalogue and much larger curriculum require backend services and additional content.
